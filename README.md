# Node.js Authentication API

A secure authentication system built with Node.js, Express, MongoDB, JWT, and bcrypt.  
It provides user registration, login, logout, and protected routes using middleware.

---

## Features
- User registration with hashed passwords (bcrypt)
- Secure login with JWT token
- Logout by clearing cookies
- Protected `/profile` route with middleware
- MongoDB + Mongoose integration
- Clean folder structure (controllers, routers, middleware, models)
